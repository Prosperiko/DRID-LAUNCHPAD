# 🚀 DRID Launchpad

A full-stack **idea validation platform** where builders share startup ideas, gather community upvotes, and collect feedback — a mini Product Hunt for early-stage concepts.

**Live demo:** https://drid-launchpad.onrender.com


## The Problem

Early-stage founders and students validate ideas through scattered Google Forms, group chats, and spreadsheets — feedback gets lost, there's no single place to see which ideas people actually care about.

**DRID Launchpad centralizes that loop:** post an idea, watch the community upvote it, and discuss it in one place.

## Features

- **Accounts** — register, log in, log out (custom registration view on top of Django auth)
- **Submit ideas** — title, category, summary, and detailed description, with auto-generated unique slugs
- **One-click upvoting** — AJAX toggle, no page reload; one vote per user per idea enforced at the database level (`unique_together`)
- **Comments** — feedback threads on every idea
- **Trending page** — ideas ranked by votes and engagement
- **Discovery** — category filtering + search across titles and summaries
- **Ownership enforced server-side** — you can only edit/delete your own ideas
- **User profiles** — every author's published ideas in one place
- **Responsive UI** — Bootstrap 5, dark navbar, hero section, mobile-friendly

## Tech Stack

| Layer | Choice |
|---|---|
| Backend | Python, Django 6 |
| Database | SQLite (demo) |
| Server | Gunicorn + WhiteNoise |
| Frontend | Django templates, Bootstrap 5, vanilla JS |
| Hosting | Render |

## Quick Start

```bash
git clone https://github.com/Prosperiko/DRID-LAUNCHPAD.git
cd DRID-LAUNCHPAD

python -m venv denv
denv\Scripts\activate        # Windows
# source denv/bin/activate   # macOS/Linux

pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo          # demo content (8 ideas, votes, comments)
python manage.py createsuperuser    # your admin account
python manage.py runserver
```

Open http://127.0.0.1:8000 — register an account, submit an idea, upvote, comment.

## Deployment (Render)

- **Build command:** `pip install -r requirements.txt && python manage.py collectstatic --noinput && python manage.py migrate && python manage.py seed_demo`
- **Start command:** `gunicorn launchpad.wsgi:application`
- Set `DJANGO_SECRET_KEY` in Render's environment variables

## Known Limitations

- SQLite on Render's free tier resets on redeploys — by design for this demo; migrations and the seed command run at build time
- No email verification or password reset flow yet
